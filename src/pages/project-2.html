About Project

Background

Dengue patients may require rapid and consistent classification, particularly in distinguishing between Dengue Fever (ICD-10 A90) and Dengue Hemorrhagic Fever (ICD-10 A91). At Rumah Sakit Aulia, the classification process was performed manually based on clinical and laboratory findings, which could lead to variations in assessment and take additional time during patient management.

This project was developed as a Clinical Decision Support System (CDSS) using machine learning to assist in classifying dengue patients based on ICD-10 codes. The study applies the CRISP-DM methodology and a Decision Tree algorithm, using patient age, gender, platelet count, hematocrit, hemoglobin, and leukocyte count as predictor variables. The resulting model was integrated into a web-based prototype using Streamlit to provide classification results in real time.

Key Features

System Capabilities

  • ICD-10 Classification — Classifies dengue patients into A90 (Dengue Fever) or A91 (Dengue Hemorrhagic Fever) based on clinical and laboratory data.
  • Clinical Data Input — Accepts six predictor variables: age, gender, platelet count, hematocrit, hemoglobin, and leukocyte count.
  • Decision Tree Model — Uses a Decision Tree classification model to generate interpretable classification results.
  • Class Weighting — Applies class weighting to address the imbalance between A90 and A91 classes during model training.
  • Model Evaluation — Evaluates model performance using accuracy, precision, recall, F1-score, and confusion matrix.
  • Feature Importance Analysis — Provides insight into the contribution of each predictor, with platelet count identified as the most influential feature in the final model.
  • Web-Based Prediction — Integrates the trained model and preprocessing pipeline into a Streamlit web application for real-time classification.
