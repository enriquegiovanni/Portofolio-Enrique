# 🚀 Portfolio Website - Enrique Giovanni

Welcome to **Enrique Giovanni**'s Portfolio Web repository. This interactive and modern portfolio website is built to showcase my professional profile, experience, skills, and featured projects in **Full-Stack Web Development** and **Data Science**.

---

## 🌟 Key Features

- **Modern Dark Mode Aesthetic**: Sleek design featuring custom dark mode color palettes & subtle glassmorphism styling.
- **Scroll Reveal Animations**: Smooth entry animations triggered on scroll via JavaScript `IntersectionObserver`.
- **Interactive Project Detail Pages**: Dedicated project showcase pages (`project-1.html` & `project-2.html`) equipped with image galleries and fullscreen Lightbox modals.
- **Direct CV Download**: One-click download button for my Curriculum Vitae (PDF).
- **Fully Responsive Layout**: Seamlessly adapted for all screen sizes (Desktop, Tablet, and Mobile).

## 💻 Featured Projects

### 1. 🏸 Badminton Court Booking Website (GOR Ratu Jaya)
A web-based badminton court reservation system that simplifies online court booking for customers and streamlines reservation management for court administrators.
- **Role**: Full-Stack Developer
- **Features**: Online Court Booking, Schedule Availability, Booking Confirmation, Admin Dashboard, Booking & Court Management, Operating Hours.
- **Technologies**: Laravel, PHP, MySQL, HTML5, CSS3, JavaScript, Bootstrap, XAMPP, Figma.

### 2. 🏥 Clinical Decision Support System for Dengue Fever Based on ICD Codes
A web-based Clinical Decision Support System (CDSS) built to assist medical personnel in diagnosing Dengue Hemorrhagic Fever (DHF) based on ICD code classification using Machine Learning algorithms.
- **Role**: Researcher & Developer (Undergraduate Thesis)
- **Technologies**: Python, Streamlit, Pandas, Scikit-learn, Matplotlib, ICD Coding.
- **Repository**: [PROJECT-SKRIPSI-SPK-ICD](https://github.com/enriquegiovanni/PROJECT-SKRIPSI-SPK-ICD.git)

## 🛠️ How to Run Locally

You can open and preview this portfolio website locally without any complex installation process:

1. **Clone this repository:**
   ```bash
   git clone https://github.com/enriquegiovanni/Portofolio.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Portofolio
   ```
3. **Open the website:**
   - Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, launch via the **Live Server** extension in VS Code for live reloading.
